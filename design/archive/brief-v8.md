## 零、为什么再改一次（v7 → v8 的事实依据）

依据是 `prototype/shots-v7/*.png` 的实测读数，不是观感争论：

1. **页头吃掉三分之一屏。** 400×905 的面板里，反白页头（品牌行 + 分段轨道 + T0 + 结论句 +
   两行说明 + 双按钮）实测占 262–300px。首屏剩下不到 600px，只放得下一条待办 + 一条线索。
   首屏的那块黑在使用前**不承载任何可操作信息**——它承载的是一个数、一句话和两个按钮。
2. **两栏台账在 400px 上不成立。** v7 行结构是「竖条 / 标题（1fr）/ 右对齐等宽元信息」。
   真实标题是 20–30 字中文，折 3 行；元信息又被右对齐挤成第 4 行，且与标题**视觉交错**
   （见 `shots-v7/capture-light.png` 第 3 行：「打开的弹窗，在 windows 系统中…」与
   「问题 · 未开始」错位重叠）。v7 的修法是「标题吃满整行 + 元信息换行右对齐」，
   结果行高从 40 涨到 76–96，且左右两栏基线彻底脱钩。
3. **反相页头在浅色下是一块纯黑**，全页唯一重色块放在「信息密度最低」的位置，
   视觉权重与实际信息量相反。深色主题下它翻成近白块，同一页在两种主题里像两个产品。
4. **分段导航是药丸轨道**（8px 圆角 + 内凹底），与「台账 / 规则线」的语言互斥；
   且 5 个入口挤在 34px 高轨道里，选中态靠「白底抠出」，在深色下读作第二个按钮组。

结论：v7 的问题不是「不够精致」，是**结构把预算花在了页头**。
v8 的动作是**把页头从「色块」降级为「读数条」**，把省下的垂直空间还给台账。

技能依据：ui-ux-pro-max（Data-Dense Dashboard，density 9/10；"numbers are the content"）+
frontend-design（"one anchor per page"）+ accessibility-audit（§七 的对比算术）。

## 一、风格定位：**校样栏（Proof Margin）**——明确选一个，不含糊

一句话：**一页纸，左边缘一条校样栏（序号 + 状态刻度），右边单栏文字；
顶部是三行读头（品牌 / 导航 / 读数），不是一块色块。**

| 手法 | 落点 |
|---|---|
| 读头（三行） | 品牌行 28px + 文本导航行 36px + 读数条 72–96px。**无实底色块**，靠 1px 规则线收口 |
| 校样栏 | 行左侧 22px 序号列（等宽 11px，`01 02 03`）+ 面板最左缘 2px 状态刻度（满行高） |
| 单栏正文 | 标题 14/22（≤2 行），元信息 12/18 紧随其下**左对齐成一行**，不再右对齐抢宽度 |
| 工具带 | 搜索 / 类型 / 捕获：`module-platform` 底 + 上下两条 l2 线，圆角 0，负 margin 满幅 |
| 状态 | 2px 刻度（面板边缘）+ 元信息里的状态词。**文字永远在场**（WCAG 不只靠颜色） |

### 明确拒绝（写下来防漂移）

- ❌ 反相整块页头（v7 的病根，§零-1/3）。
- ❌ 卡片墙：纸面上不出现同时带 `border + border-radius + padding` 的分组容器（浮层与输入控件除外）。
- ❌ 用灰阶差表达层级（v6 已证伪：浅色下 249/250/245 差 ≤5 个单位）。
- ❌ 玻璃拟态 / blur / 彩色阴影 glow / 紫蓝渐变 / `bg-clip-text`。
- ❌ Emoji 结构图标；结构性标记一律等宽文字、2px 刻度、CSS 绘制的三角。
- ❌ 卡片 hover scale、滚动 fade-up；动效只由用户动作触发。
- ❌ 中文整句当页最大字号。
- ❌ 右对齐元信息列与标题抢同一行宽度（v7 的病根，§零-2）。

## 二、色彩策略

| 角色 | 取值 | 规则 |
|---|---|---|
| 纸面 | `var(--dsw-alias-bg-base)` | 全页最亮一档；行 hover 才允许换底 |
| 读头底 | 同纸面 | **不设底色**，只靠底部 1px `border-l2` 与纸面分隔 |
| 工具带底 | `var(--dsw-alias-bg-module-platform)` | 只给工具带 / 正文块；分组不用它 |
| 行 hover | `var(--dsw-alias-card-fill-hover)` | 只给可点行，负 margin 满幅 |
| **强调蓝** | `var(--dsw-alias-state-business-primary)` | 选中 Tab 下划线、链接、meter 填充、**全部焦点环**、刻度「较可信」 |
| 主操作（纸面） | `var(--dsw-alias-button-info-fill)` 实底 + `bg-base` 文字 | 全页唯一蓝实底 |
| 主操作（读头） | `label-primary` 实底 + `bg-base` 文字（墨块） | 与蓝实底**互斥**，名额由 `ownsPrimary` 分配 |
| 文本三档 | `label-primary / secondary / tertiary` | 正文必须 primary；占位与序号用 tertiary |
| 边界 | `border-l2`（分组/工具带）`l3`（控件）`l1`（行内发丝） | l1 只出现在两行内容之间 |

**焦点环一次定死（单色，不再是两套）**：`outline: 2px solid var(--accent)`，`outline-offset: 2px`；
输入类 `offset: -1px`（贴边）。因为 v8 取消了反相块，**全站只剩一种焦点环颜色**——
深色主题下 `accent` 自动变浅蓝（宿主别名），不需要第二套规则。

**禁止**：`brand-primary` 作实底；字面色值（`tokens.css` 除外）；表外色相；同语义两套色；
用 `label-on-color` 作蓝底文字（宿主两套主题都是白，深色蓝底白字 ≈2.3:1，v6 评审 P1-4 的裁决沿用）。

## 三、字体与层级

字阶 5 档：`40 / 24 / 16 / 14 / 12`，行高 `44 / 32 / 24 / 22 / 18`。

| 档 | 用途 |
|---|---|
| **T0 40** | **全页唯一最大字号，且只给数字**：读头那个「现在压着几件事 / 每请求多少钱」。中文不许用 T0 |
| T1 24 | 仅详情标题（纸面最大，低于 T0） |
| T2 16 | 条目标题以外的次级数字（成本行数字）、空态标题 |
| T3 14 | 正文、行标题、按钮、输入 |
| T4 12 | 元信息、状态词、导航、分组小标（+0.08em）、序号、计数 |

- **第二字体身份：所有数字与元信息一律等宽 + `tabular-nums`**（tokens、日期、路径、计数、序号）。
- 字重两档 400/600；T0/T1 用 600。
- 中文字距：大字号 `-0.02em`；小标（T4 全大写式分组名）`+0.08em`；**正文与标题不加字距**。
- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`
  （macOS 走 PingFang SC，Windows 走微软雅黑；不引入 Web 字体）。
- 正文行高 1.6–1.8：T3 14/22 = 1.57（密排下限），说明性段落用 14/24；T4 12/18 = 1.5 只用于元信息。
- 数字/单位之间不断行：`white-space: nowrap` 于 `.meta` 的数值片段。
- 读头结论句：**T3 单行，≤20 字**（lint 机检这条）。
- 标点：标题与元信息用「·」分隔并留 `4px` 两侧间距，不在行首出现「·」

## 四、形状与间距

- 间距六档 4/8/12/16/24/32，加节奏硬规则：
  行内 4；组内 8；**相邻区块之间 ≥16**；读头内 8/12；纸面左右 16。
- 圆角三档：`0` = 行、规则线、工具带、序号、meter；`4` = 控件（按钮/输入/类型签）；
  `8` = 面板外框；`12` = 浮层。
- 行节奏：紧凑行 **min-height 44px**（标题 1 行 + 元信息 1 行 + 上下 8），
  两行标题自然长到 66px，不设固定高（固定高正是 v7 折行崩坏的原因）。
- 阴影：0 处，除浮层（值由 `bg-mask-1` 派生）。

## 五、主题契约（宿主机制，沿用 v6/v7）

1. 只允许 `var(--dsw-alias-*)` / `var(--dsw-specific-*)` + `color-mix` 派生；禁止字面色值
   （`tokens.css` 例外，它是宿主值复刻，落地时整段删除）。
2. 禁止 JS 读取或缓存计算后的颜色；禁止自建 `.dark` class；切主题 = `body[data-ds-dark-theme]`。
3. 原型 `tokens.css` 逐字复刻宿主两套别名；切 `data-ds-dark-theme` 即回归测试。
4. **v8 的新算术**：读头不再依赖反相，所以两套主题下对比都来自宿主自身
   （浅 `label-primary` on `bg-base` ≈ 17.4:1；深 ≈ 16.9:1）。
   读头里允许直接使用 `label-secondary`——**这是 v8 与 v7 §二 的显式差异**：
   v7 禁用它是因为它压在反相块上（3.25:1），v8 没有反相块，12px secondary on paper
   浅色 ≈ 5.9:1、深色 ≈ 8.4:1，达标。

## 六、动效原则

| 项 | 规则 |
|---|---|
| 时长 | 100ms 态切换 / 160ms 浮层进出 |
| 缓动 | `cubic-bezier(0.2, 0, 0, 1)` |
| 触发 | 只由用户动作（hover / focus / active / 展开） |
| 禁止 | 滚动 fade-up、slide-up、hover scale、自动轮播 |
| 加载 | 骨架 44px（与真实行等高），呼吸 1.2s；**不位移** |
| 降级 | `prefers-reduced-motion: reduce` → 全部 animation/transition 关闭；替代指示 = 骨架静止但仍可辨（底色在）+ 按钮 disabled + 文案「读取中」 |

## 七、可达性硬约束

1. 交互元素齐 hover / active / focus-visible 三态；焦点环 `2px solid accent`、offset 2px（输入类 -1px）。
2. 正文 ≥4.5:1；元信息用 `label-secondary`（浅 ≈5.9:1）。**不许**用 `label-tertiary` 承载信息
   （只给占位、序号、装饰刻度）。
3. 主按钮文字色 = `bg-base`；hover 用 `filter: brightness(0.92)`，不切 `button-info-hover`。
4. 状态不只靠颜色：2px 刻度 + 状态词同时存在。
5. `list-style:none` 的列表容器必须显式 `role="list"`。
6. 浮层：打开移焦、Esc 关闭、关闭回焦；播报用常驻隐藏 `aria-live`。
7. 读头是 `banner` 语义；导航 `role=tablist` + `aria-controls` 指向 `#paper`（`role=tabpanel`）。
8. 可点区域：按钮 min-height 28（≥ WCAG 2.2 AA 的 24），独立按钮 min-width 44。

## 八、v8 自加禁令（可机检）

1. **纸面 0 容器**：除浮层与输入控件外，没有 `border + radius + padding` 三者同在的分组容器。
2. **每页恰好 1 个 T0**，且该元素文本含数字（截图与 DOM 双查）。
3. **读头结论句 ≤20 字且不折行**（lint 静态查 `MO.mastCopy(` 字面量长度）。
4. **主操作名额整页唯一**：墨块（读头）与蓝实底（纸面）互斥，由 `ownsPrimary` 分配。
5. **`.remember-*` 类块是回归锚点**：v4 重写时整段删除导致弹窗「挂载但不可见」。
6. **流程术语不上界面**（该补了 / 爬升 / 减重 / 锚点校验 → 用户语言）。
7. **首屏必须能回答「所以我现在点哪里」**：读头数字 + 一句结论 + 至多一个主操作，三者齐全。
8. **元信息不得右对齐进标题行**（v7 的病根）：`.row-meta` 必须是标题下方的独立行。

## 九、差异化声明（区别于 AI 默认审美的 3 处具体决策）

1. **页头不做色块，做「读数条」。** 品牌 / 导航 / 读数三行，底就是纸面，只靠 1px 规则线收口。
   理由：v7 用反相块换来识别度，代价是 33% 首屏（§零-1），而它承载的信息量是三行文字。
   把权重从「面积」改成「字号 + 等宽数字」，识别度改由左缘校样刻度承担——这也是本版名字的来源。
2. **序号进左栏，数字进元信息行尾。** 每行左边缘一个 `01/02/03` 等宽序号，右边缘 2px 状态刻度。
   理由：这是「台账」唯一能用满 400px 的排法——它让两栏结构（序号 / 正文）永不与正文抢宽度，
   而 v7 的第三栏（右对齐元信息）正是折行崩坏的直接原因。序号同时给了「这一屏有几条」的第二读数。
3. **主操作用墨块，蓝只做「状态与位置」。** 蓝实底只出现在纸面主操作与 meter 填充上；
   选中 Tab 用 2px 下划线、链接用蓝字、焦点环用蓝线。
   理由：蓝实底在深色主题下要与 `label-on-color`（白）凑对比会失败（v6 P1-4），
   而墨块（`label-primary` ↔ `bg-base`）两套主题都 ≥16:1；把蓝收窄到「位置信号」后，
   同一屏不会出现两个抢注意力的实心块。

## 十、IA v8（信息架构，含四态）

5 个任务入口不变（v4 起）：今天 / 记一条 / 待办 / 记忆 / 库健康。
每页 = 读头（导航 + 唯一 T0 + 一句结论 + 必要时唯一主操作）+ 纸面。

| 页 | 唯一核心任务 | 读头读数（T0） | 纸面内容（自上而下） | 主操作位置 |
|---|---|---|---|---|
| 今天 | 1 秒知道现在做哪件事 | 压着件数 | 捕获工具带 → 线索台账（4 行） | 读头（纸面捕获降次按钮） |
| 记一条 | 写进 INBOX 并看到它进去了 | 记录条数 | 类型签工具带 → 输入 → 隐私说明 → 最近记的台账 | 纸面（读头无按钮 → 蓝名额给「存进去」） |
| 待办 | 清掉压着的事 | 压着件数 | 三个分组台账（拍板 / 流转 / 补库），展开行 | 读头（拍板首条确认）；无拍板时给纸面 |
| 记忆 | 找到某条并处理它 | 记忆条数 | 工具带（搜索 + 状态/域筛选）→ 紧凑台账；详情整页 | 纸面（「搜」）；详情态给读头 |
| 库健康 | 判断贵不贵、该不该维护 | 每请求 tokens | 成本三行（T2 右对齐数字）+ meter + 作业 + 导出 | 纸面（空态给「去写第一条」） |

**四态逐页可达**（原型控制台 + `#pane/phase` 深链）：

- loading：读头数字显示 `—`（不显示 0），纸面 44px 骨架行。
- empty：读头说真话（「现在没有待办」），主操作名额按 §八-4 转移；纸面空态带说明 + 出口。
- error：读头保留品牌行与导航（不许整页塌成一块红），纸面错误态含下一步动作 + 示例值。
- success：就地反馈（`inline-done`），不弹层、不盖内容；可撤销必须真有撤销按钮。
