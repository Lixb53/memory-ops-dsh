# 设计契约 · 记忆库 v9（唯一真相源）

> 取代 v8「校样栏」（原文归档于 [`archive/brief-v8.md`](archive/brief-v8.md)）。
> 锁定时间：2026-11-21。方向已由用户拍定（`directions-v9.md` §三 修订推荐组合）。
> **本轮范围**：整个产品 UI——`prototype/`（4 表面中的主工作区）。不改 `packages/`。
> 与 v8 的差别根源：**画布从 400px 侧栏改成 1614×900 主区页面**（用户实测读数），
> 因此 v8 的「单栏纸面」不再是地基；但 v8 的令牌、焦点环、T0 只给数字、墨块主操作四条**沿用**。

## 零、画布与三栏事实（先定死，再谈风格）

| 项 | 值 | 依据 |
|---|---|---|
| 画布 | **1614 × 900**（内容区，含页面内边距） | 用户截图红框读数：x 273→1887、y 47→946，比例 1.79:1 |
| 外壳内边距 | 左右 24 / 下 24 / **上 0**（实测） | 顶条 72px 自带上方留白；上边距再加会把主区压到 736，health 首屏溢出 79px |
| 左轨 | **212** | 5 个分区，44px 行高 + 24 上下留白 |
| 中栏 | **946**（1fr） | 1614 − 48 − 212 − 24 − 360 − 24 = 946 |
| 检视栏 | **360** | 单行标题编辑 + 上下叠 diff 的可读下限 |
| 列间距 | 24 | 相邻区块 ≥24（v8 为 16，桌面放宽） |
| 垂直预算 | 顶条 72 + 主区 **776** + 状态条 28 + 下边距 24 = 900（实测） | 主区必须 0 滚动，scripts/measure-v9.mjs 断言 paneOverflow=0 且 pageOverflow=0 |

**推论（写下来防漂移）**：946 宽的中栏在 14px 中文下若排满约 105 字/行，**违反 45–75 字符可读上限**，
所以中栏内容一律受 `max-width: 720px` 约束（长段落 640），剩余宽度交给列（来源/tokens/状态），
不留给正文行宽。这条同时是「为什么不能是单栏纸面」（D1 判死）的直接理由。

## 一、风格定位：**三栏工作台 · 双车道**（Workbench / Two-Lane）—— 选一个，不含糊

一句话：**一张永远开着检视栏的账台——左边选什么，右边就看什么、改什么；中栏顶部永远压着一条「每请求都在」。**

四个承重决定（试运行三个月内不许换）：

| 承重 | 落点 | 为什么是它 |
|---|---|---|
| 左轨（212） | 宿主 `sidebar-fill` 底、零圆角、右缘 1px `border-l2`、选中 2px 左刻度 | 用宿主侧栏色分区，不引入新色块层级；深色下不会变成第二套按钮组（v7 药丸轨道教训） |
| 中栏（946） | 纸面 `bg-base`；顶部 72px「每请求都在」窄带 + 下方清单 | 双车道：推送通道做成**结构**而不是 KPI 卡 |
| 检视栏（360） | `bg-module-platform` 底 + 左缘 1px `border-l2`；内容随选中项替换 | 详情、编辑、diff 三件事同屏，R11 的「三件缺一不可」才成立 |
| 顶条（72） | 判定句（T3 ≤20 字）+ 唯一 T0 读数 + 至多一个主操作 | 体检报告式开场（D5），先给结论再给清单 |

### 明确拒绝（防漂移）

- ❌ 卡片墙（`border + radius + padding` 三者同在的分组容器）；检视栏用**底色 + 单边线**分区，不用框。
- ❌ 抽屉 / 弹层承载 V2 编辑（1614 下抽屉=浪费可用宽度，且在 360 栏内能一次看完）。
- ❌ 把成本做成 4 个 KPI 卡（那是 PRD 原型现状，读作仪表盘，把「哪条能关」藏起来）。
- ❌ 灰阶差表达层级（v6 已证伪：浅色下 249/250/245 差 ≤5 单位）——只用 1px 线与文字。
- ❌ 药丸轨道导航、卡片 hover scale、滚动 fade-up、玻璃拟态、渐变字、紫蓝渐变、`#0D1117` 底。
- ❌ Emoji 结构图标；结构标记一律等宽文字 / 2px 刻度 / CSS 三角。
- ❌ 中文整句当页最大字号（T0 只给数字）。
- ❌ 右对齐元信息列与标题抢同一行宽度（v7 病根）；元信息必须是标题下方的独立行或独立列。

## 二、色彩策略

| 角色 | 取值 | 规则 |
|---|---|---|
| 纸面（中栏） | `var(--dsw-alias-bg-base)` | 浅色下全页最亮一档 |
| 左轨 / 检视栏 | `color-mix(in srgb, bg-base 94%, label-primary 6%)` | **两侧面与纸面差同一档**：浅色变暗、深色变亮（宿主暗色惯例）。不用 `sidebar-fill`/`bg-module-platform`——那两个值在深色下比纸面亮两档，会把 360 栏变成全屏最亮块（评审 A16） |
| 行 hover | `var(--dsw-alias-card-fill-hover)` | 只给可点行，负 margin 满幅 |
| 强调蓝 | `var(--dsw-alias-state-business-primary)` | 选中刻度、`:focus-visible` 环、meter 的「你能动」段、链接 |
| 主操作 | `var(--dsw-alias-label-primary)` 实底 + `bg-base` 文字（墨块） | 全页唯一实心块；蓝**不许**做实底，`.btn-primary` 已从原型与机检名单移除（评审 A22） |
| 文本三档 | `label-primary / secondary / tertiary` | 正文只许 primary；tertiary 仅占位、序号、装饰 |
| 语义 | `warn-primary`（超预算 / 待复核）、`danger`（驳回 / 删除）、`ok`（已确认） | 每语义只一套色，且**必须同时有文字** |
| 边界 | `border-l2`（分区）`l3`（控件）`l1`（行内发丝） | l1 只出现在两行内容之间 |

**焦点环一次定死**：`outline: 2px solid var(--dsw-alias-business-primary); outline-offset: 2px`；
输入类与贴边控件 `offset: -1px`。**全站只有这一种焦点环**，深色主题靠宿主别名自动变浅，不写第二套。

**禁止**：字面色值（`tokens.css` 除外）、`brand-primary` 作实底、表外色相、同语义两套色、
用 `label-on-color` 作蓝底文字（深色下 ≈2.3:1，v6 P1-4 裁决沿用）。

## 三、字体与层级

字阶 5 档：`44 / 28 / 18 / 14 / 12`，行高 `48 / 36 / 26 / 22 / 18`。

| 档 | 用途 | 约束 |
|---|---|---|
| **T0 44** | **每页唯一最大字号，且只给数字**：该页核心任务的读数（见 §六 表） | 每页恰好 1 个；中文一律不许用 T0 |
| T1 28 | 检视栏标题、页面级标题 | 每页 0–1 处 |
| T2 18 | 分区名、桶名、次级数字 | |
| T3 14 | 正文、清单标题、按钮、输入 | 长段落用 14/24（1.71），密排表格 14/22（1.57 下限） |
| T4 12 | 元信息、状态词、表头、序号、计数 | 表头与分组小标 `+0.08em`；**正文与标题不加字距** |

- **第二字体身份**：所有数字、日期、路径、计数、序号一律等宽 + `font-variant-numeric: tabular-nums`。
- 字重两档 400 / 600；T0、T1、选中项用 600。
- 中文字距：仅 T4 分组小标 `+0.08em`；大字号 `-0.02em`；正文与标题**不加**。
- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`（不引 Web 字体）。
- 中英混排：中文与拉丁/数字之间保留自然间距，数字带单位不断行（`.num { white-space: nowrap }`）。
- 标点：元信息用「·」分隔并留 4px 两侧；避头尾 `line-break: strict`；「」`（）` 不在行首。
- **可点尺寸**：独立按钮 `min-width 88 / min-height 32`；行内小按钮 `min-width 44 / min-height 28`；
  输入 `min-height 36`。桌面不做 24px 的下限贴地。

## 四、形状与间距

- 网格 4 基准，档位 `4 / 8 / 12 / 16 / 24 / 32`。节奏硬规则：行内 4；组内 8；**相邻区块 ≥24**；页面左右 24。
- **发丝级间隙 2px**：正式档位之外的一档，只用于行内基线、meter 段间、品牌两行之间；**不得用于区块之间**（评审 A25 裁决）。
- **圆角三档（节奏）**：`0` = 行、带、轨、表、分割线、刻度、meter（**绝大多数面积是 0**）；
  `6` = 控件（按钮 / 输入 / 分段开关 / 类型签）；`10` = 只给真正浮起的东西（`/remember` 浮层、确认对话框）。
- 行基准：清单行 **58**（标题 1 行 + 元信息 1 行，实测）/ **80**（标题 2 行，实测）；表格行 **40**；
  上带 **72**（折起 28）；左轨项 **44**。**不设固定行高**——固定高是 v7 折行崩坏的直接原因。
- 阴影：**0 处**，除浮层（`bg-mask-1` 派生）。
- 列宽节奏（中栏 946）：标题 `1fr`（≤720）/ 来源 `200` / tokens `96` 右对齐 / 状态 `88`。
  检视栏 360：内边 20，内容宽 320。

## 五、主题契约（沿用 v8）

1. 只允许 `var(--dsw-alias-*)` / `var(--dsw-specific-*)` + `color-mix` 派生；禁止字面色值（`tokens.css` 例外）。
2. 禁止 JS 读缓存色值；禁止自建 `.dark`；切主题 = `body[data-ds-dark-theme]`。
3. 原型 `tokens.css` 逐字复刻宿主两套别名，切 `data-ds-dark-theme` 即回归测试。
4. 对比：正文 `label-primary` on `bg-base`（浅 ≈17.4:1 / 深 ≈16.9:1）；元信息用 `label-secondary`
   （浅 ≈5.9:1 / 深 ≈8.4:1）达标；**`label-tertiary` 不得承载信息**。

## 六、动效原则

| 项 | 规则 |
|---|---|
| 时长 | 120ms 态切换（hover / 选中 / 展开 / 双面开关）；180ms 检视栏内容替换 |
| 缓动 | `cubic-bezier(0.2, 0, 0, 1)` |
| 触发 | **只由用户动作**（点击、悬停、聚焦、展开、切换）；不许进页自动播放 |
| 检视栏替换 | 只做 `opacity` 交叉（0→1），**不做位移**；`prefers-reduced-motion` 下直接切 |
| 加载 | 骨架 44px（与真实行等高），呼吸 1.2s；**不位移** |
| 降级 | `reduce` → 全部 animation/transition 关闭；替代指示 = 选中 2px 刻度即时出现 + 骨架静止仍可辨（底色在）+ 文案「读取中」 |

## 七、可达性硬约束

1. 交互元素齐 `hover / :active / :focus-visible` 三态；焦点环见 §二（单色、offset 2／输入 -1）。
2. 正文 ≥4.5:1；元信息 `label-secondary`；状态**不只靠颜色**：2px 刻度 + 状态词同时存在。
3. 主按钮文字 = `bg-base`；hover 用 `filter: brightness(0.92)`，不切 `button-info-hover`。
4. `list-style:none` 的列表容器必须显式 `role="list"`。
5. 浮层：打开移焦、Esc 关闭、关闭回焦；播报用常驻隐藏 `aria-live`。
6. 左轨 `role="tablist"` + `aria-controls` 指向 `#pane-host`（`role="tabpanel"`）；顶条 `banner`；状态条 `role="status"`。
7. 检视栏是 `aside`，标题 id 供 `aria-labelledby`；选中行 `aria-current="true"`。
8. 双面开关是 `role="switch"`（不是 tab），`aria-checked` 同步。

## 八、v9 自加禁令（可机检）

1. **中栏 0 容器**：除浮层与输入控件外，没有 `border + radius + padding` 三者同在的分组容器。
2. **每页恰好 1 个 T0**，且该元素文本含数字（截图 + DOM 双查）。
3. **判定句 ≤20 字且不折行**（lint 静态查 `MO.lede(` 字面量长度）。
4. **主操作整页唯一**：墨块只出现在顶条或检视栏底部，二选一，由 `ownsPrimary` 分配。
5. **`.remember-backdrop` 必须存在且 `position: fixed`**（v4 血案回归锚点：弹窗挂载但不可见）。
6. **中栏正文行宽 ≤720px**（`max-width` 硬约束，见 §零 推论）。
7. **流程术语不上界面**（该补了 / 爬升 / 减重 / 锚点校验 → 用户语言：`缺 1 条记忆` / `可以合并` / `变短` / `核对引用`）。
8. **error ≠ empty ≠ 0**：读不到时数字显示 `—` 并给原因串，禁止渲染成 `0` 或空态；**empty 态顶条读数与判定句也必须跟着换**（评审 A3/A4）。
9. **蓝实底零处**：`.btn-primary` 不得出现在原型与机检必检类名单里（评审 A22）。

## 九、差异化声明（区别于 AI 默认审美的 3 处具体决策）

1. **检视栏常驻 360，而不是抽屉或弹层。**
   理由：R11 要求「diff + tokens 前/后/Δ + 生效时机」三件同屏才可保存；抽屉在 1614 宽下是把可用宽度浪费掉，
   而且抽屉套抽屉必迷路（D3 的代价）。常驻栏还消掉了「点了行才出现」的发现成本。
   这是与「列表页点开看详情」这一 AI 默认形态的正面分歧。

2. **diff 用上下叠，不用并排两列。**
   理由：360px 栏内并排每列只剩约 150px → 15 字/行，中文标题必折；上下叠（删除行 2px `danger` 左刻度 + 删除线，
   插入行 2px `ok` 左刻度）保住可读性与行号对齐，代价是要滚动比对。并排是 GitHub 式默认审美，在这个宽度不成立。

3. **成本做成一条 72px「每请求都在」窄带 + 四桶堆叠 meter，不做 4 个 KPI 卡。**
   理由：卡片把「合计 = 四桶之和」这条 R1 硬规则打散成四个孤立数字，用户要自己心算；
   窄带 + 连续 meter 让「哪条占了 71 / 关掉能省多少」变成同一眼的两个读数。PRD 原型现状正是卡片墙，
   本版是对它的显式否决，理由不是审美而是信息结构。

## 十、IA v9（5 分区 + V1/V2/V3，含四态）

导航在左轨（不占垂直空间）。顶条三段：`品牌 + 分区名 | 判定句（T3 ≤20 字）| T0 读数 + 单位`。
主操作**不在顶条**：固定在检视栏底部（记一条例外，在输入框旁），整页唯一（评审 A29）。

| 分区 | 唯一核心任务 | 顶条 T0（数字） | 中栏（上带 + 清单） | 检视栏 |
|---|---|---|---|---|
| 今天 | 1 秒知道先做哪件 | 压着件数 | 上带（置顶 N 条 · 229）→ 今日线索 ≤6 行 → 捕获入口 | 选中线索详情 + 完成/推迟 |
| 记一条 | 写进去并看到它进去了 | 今日已记条数 | 类型签 + 文本域 + 隐私提示 + 存 | 隐私拦截解释 / 落点路径 / 撤销回执 |
| 待办 | 清掉压着的 | 压着件数 | 三段台账（待拍板 / 流转中 / 待补库） | 确认 / 驳回（带理由）/ 流转 |
| 记忆 | 找到某条并处理它 | 条目数 | 双面开关（内容面 ⇄ 成本面）+ 搜索 + 清单 | 条目详情（来源·证据·锚点）+ 状态动作 |
| 库健康 | 判断贵不贵、该不该维护 | **每请求 tokens（229）** | 四桶堆叠 meter + 四行小计（V1）+ 版本五项（V3）+ 作业 | 选中桶→条目级明细（V1）/ 置顶编辑（V2）/ 差异清单（V3） |

**V1/V2/V3 的落点**（PRD §2.1：不新增一级分区）：桶行在**中栏**展开（可见性最高），
选中条目后**检视栏**承担属性 + 「去编辑」；编辑态（diff/Δ/生效时机）在检视栏内完成；版本差异清单在检视栏。

**四态逐页可达**（`#pane/phase` 深链 + 控制台）：

- `loading`：T0 显示 `—`（不显示 0）；中栏 44px 骨架行；检视栏骨架 3 行。
- `empty`：顶条说真话（「现在没有待办」）；主操作名额转移（§八-4）；中栏空态给说明 + 出口；检视栏提示「选一条看详情」。
- `error`：**顶条保留品牌与导航**，T0 为 `—`；中栏红条 = 原因 + 下一步 + 示例值；检视栏不塌。
- `success`：就地反馈（行内 `inline-done`），不弹层；可撤销必须真有撤销按钮；`aria-live` 播报。

## 十二、假设与验收标准

**假设（用户未指定；要翻转改这三条）**

- **A1** 画布 1614×900 为唯一目标尺寸，不做响应式断点（1614 之外不保证）。
- **A2** 数据用 `prototype/data.js` 的真实库快照；四桶数字与 `core/src/pinned.ts` 口径一致（229 = catalog 0 + frame 171 + injected 58 + toolschema 0 的可复算关系，见 data.js 注释）。
- **A3** 不改 `packages/`；不接宿主真实 skills/版本服务，V3 用探测三态模拟（`host-managed` / `not-updatable` / `blocked`）。

**验收标准（可检查，逐条给检查方式）**

| # | 标准 | 检查方式 |
|---|---|---|
| 1 | 1614×900 下 5 页首屏 0 滚动（中栏与检视栏各自 `scrollHeight ≤ clientHeight`） | 截图 + DOM 量测脚本 |
| 2 | 三栏实测 212 / 946 / 360，列间距 24 | DOM `getBoundingClientRect` |
| 3 | 每页恰好 1 个 T0 且文本含数字 | DOM 查 `.t0` 计数 + 正则 |
| 4 | 判定句 ≤20 字、单行不折行 | `MO.lede(` 字面量 + `scrollWidth ≤ clientWidth` |
